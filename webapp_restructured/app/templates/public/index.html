System Features

Advanced AI prediction with a user-friendly interface for health officers and the public

AI-Powered Predictions

STGNN model analyzes historical case data, climate patterns, and NDVI satellite vegetation indices to predict dengue outbreaks with explanations.

Real-Time Monitoring

Track dengue cases across all 5 regencies in real-time. View interactive trends, statistics, and color-coded risk levels at a glance.

Smart Recommendations

Automated health recommendations based on predicted risk levels, helping health offices take proactive measures to prevent outbreaks.

Multi-Role Access

Role-based access for system administrators, district health officers (per regency), and the general public — each with tailored views.

Climate Integration

Automatically fetches NASA climate data (temperature, humidity, rainfall, etc) and NDVI satellite imagery monthly to continuously improve model accuracy.

Simplified Data Management

One-click data updates replacing complex manual workflows. Upload, process, and generate predictions in minutes.

How It Works

A four-step pipeline from raw data to actionable predictions

1
Data Collection
Case data entered by district health officers. Climate and NDVI satellite data fetched automatically via NASA APIs.
2
Data Processing
Raw data cleaned, imputed, and normalized. Spatio-temporal features constructed across all 5 regencies.
3
AI Model Prediction
STGNN model analyzes spatial correlations and temporal trends to generate next-month dengue case predictions.
4
Risk Communication
Predictions displayed as risk-coded dashboard cards with actionable health recommendations for officers.
