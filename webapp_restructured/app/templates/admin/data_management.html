    NDVI Pipeline — 4 Steps Required
    NDVI data requires a 4-step processing pipeline. Complete all steps in order.
    1
    Upload GeoTIFF Files
    Download NDVI .TIFF files from NASA NEO or using get_ndvi_kabupaten.py, then upload here.
    2
    Process TIFF → Values
    Extract NDVI values per regency from uploaded GeoTIFFs using ndvi_epi_week_kabupaten.py.
    3
    Impute Missing Weeks
    Fill in missing epi-week values using interpolation via ndvi_imputation.py.
    4
    Convert Weekly → Monthly
    Aggregate weekly NDVI values to monthly averages via convert_weekly_to_monthly.py.
